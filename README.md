# XAUUSD Market Dashboard

Vercel-ready static dashboard for displaying live XAUUSD market analysis.

## Current version
The UI uses demo values so it can be published immediately. It does **not** use historical EA performance, wallet/account data, or EA controls.

## Files
- `index.html` — dashboard
- `style.css` — responsive UI
- `app.js` — dashboard logic and demo data
- `vercel.json` — Vercel configuration

## Deploy
1. Upload these files to a GitHub repository.
2. In Vercel, import the GitHub repository.
3. Deploy with no build command and no framework preset required.
